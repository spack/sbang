# v1.1.0 (2026-09-04)

This is the first minor release of sbang

* Compatible with `python` and `ruby` scripts using encoding comments
* Coverage tests moved from macos to linux for performance
* Changed to 3-component versioning

# v1.0 (2020-11-18)

This is the first standalone release of `sbang`

* Completely POSIX-compatible `sbang` implementation
* Support for regular `#` shebangs, `lua`, `node`, and `php`
* Special -x handling for `perl` and `ruby`
* Unit tests with full coverage
* Standalone release number, separate from Spack
